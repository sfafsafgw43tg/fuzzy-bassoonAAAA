# InkBrowser Windows — RELEASE INCOMPLETE

**No complete, tested InkBrowser Windows release is available from this repository.**
The retained uploaded ZIP is old source, not a runtime or working installer.
The modified sources are in `manusium-native-gecko-runtime-final/windows`.
No Windows InkBrowser binaries are committed, and no runtime has yet been built,
packaged and verified here. Passing JavaScript tests is not release acceptance.

See [runtime audit, blockers and build handoff](manusium-native-gecko-runtime-final/windows/docs/inkbrowser/RUNTIME-RELEASE-STATUS.md).
The release workflow must build both pinned runtimes and pass installation and
native execution on a disposable Windows machine before its final installer
artifact may be treated as a tested release. `CANDIDATE` artifacts are unverified.
