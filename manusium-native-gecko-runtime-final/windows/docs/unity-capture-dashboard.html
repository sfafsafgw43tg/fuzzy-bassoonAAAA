Recovery path

1
RegistryUnity Capture must have a CLSID and InprocServer32 DLL. The invalid foo:bar DevicePath must be absent.
2
Windows deviceGet-PnpDevice / pnputil must show a Camera or Image device. DirectShow registry entries alone are insufficient.
3
Emulator endpointemulator @YourAVD -webcam-list must print webcam0 or another webcamN endpoint.
4
FramesThe producer must open Unity Video Capture and the host server must expose /mjpeg through adb reverse tcp:8765.

Exact troubleshooting commands

# Inspect Unity Capture and DirectShow powershell -ExecutionPolicy Bypass -File .\scripts\android\diagnose-unity-capture.ps1 # Probe the Android Emulator emulator.exe @Octo-Realme12Pro-Unity -webcam-list # Check Windows camera devices Get-PnpDevice -PresentOnly | ? { $_.Class -in @('Camera','Image') } # Check ADB reverse tunnel and receiver adb devices adb -s emulator-5554 reverse --list adb -s emulator-5554 shell pm path app.octo.avdcamera
