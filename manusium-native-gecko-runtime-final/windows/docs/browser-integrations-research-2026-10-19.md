# Privacy browser integrations — official-source verification (2026-10-19)

This note records the official-source verification used by the Browser Choice catalog. It does not claim universal spoofing, CAPTCHA bypass, fraud-control bypass, or undetectability.

- **Camoufox** — browser; patched/custom Firefox build with Playwright/Juggler integration; MPL-2.0; official project: https://camoufox.com/ ; source: https://github.com/daijro/camoufox . Official documentation warns that inconsistencies can still be detected and that the project may not be production-stable. No verified standalone Windows per-profile configuration file was found; Python launch options and persistent user-data directories are documented.
- **Cromite** — Chromium/Bromite-derived browser fork; GPL-3.0; official site: https://www.cromite.org/ ; source: https://github.com/uazo/cromite . Windows release assets and Chromium `--user-data-dir` usage are documented. Privacy features are not comprehensive; DRM and some Chromium services are unsupported.
- **Brave Browser** — Chromium-based browser with Brave Core; MPL-2.0; official download: https://brave.com/download/ ; source: https://github.com/brave/brave-core . Official documentation supports separate Chromium user-data directories. It is a normal privacy-oriented browser, not an anti-detection guarantee; deleting user data can cause loss of Rewards/Wallet data.
- **LibreWolf** — independent Firefox-based browser; MPL-2.0 for source; official site: https://librewolf.net/ ; source: https://librewolf.dev/librewolf/source . Windows support and `librewolf.overrides.cfg` / `user.js` style profile configuration are documented. Hardening can break sites; DRM and Safe Browsing are disabled by default; use Tor Browser for Tor/anonymity.
- **Chameleon** — Firefox extension/profile integration, not a browser; GPL-3.0-only; official site: https://sereneblue.github.io/chameleon ; source: https://github.com/sereneblue/chameleon . Settings import is JSON through the extension options page. WebExtension limitations and documented site incompatibilities apply.
- **CanvasBlocker** — Firefox extension/profile integration, not a browser; MPL-2.0; official listing: https://addons.mozilla.org/en-US/firefox/addon/canvasblocker/ ; source: https://github.com/kkapsner/CanvasBlocker . Settings are stored through Firefox browser storage and URL-specific rules. Protection can break sites; multiple protection extensions can harm performance.
- **CreepJS** — browser-based audit/measurement tool, not a browser; MIT; official page: https://abrahamjuliot.github.io/creepjs ; source: https://github.com/abrahamjuliot/creepjs . No standalone per-profile configuration or Windows-native download was verified.
- **FingerprintJS OSS** — client-side browser fingerprinting library, not a browser or audit application; MIT; source: https://github.com/fingerprintjs/fingerprintjs . No official per-profile configuration format was verified. The open-source package has lower accuracy than the commercial product and is affected by privacy tools/ad blockers.
- **BrowserForge** — Python automation/profile library, not a browser; Apache-2.0; source: https://github.com/daijro/browserforge . Configuration is Python API options. The official README says fingerprint injection is deprecated and directs users to Camoufox.

The implementation only exposes launch for verified browser adapters. Extensions, audit tools, and automation libraries remain explicitly non-launchable. Unsupported advanced settings cause an explicit refusal rather than silent loss.
